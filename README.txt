# Shreeshanth S — Portfolio starter

## Run locally
1. Extract the ZIP.
2. Open the `shreeshanth-portfolio` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

No build step is required. GSAP and Google Fonts load from CDNs, so an internet connection is needed for those enhancements. The page still works without GSAP.

## Before publishing — personalize these items
- Replace `YOUR_EMAIL@example.com` in `index.html` with your professional email.
- Replace the LinkedIn and GitHub profile URLs with your real profile URLs.
- Replace the placeholder GitHub project links with the actual repositories.
- Add your resume as `assets/resume.pdf` (the download link is already wired).
- Review every skill and keep only skills you can explain in an interview.
- Add exact internship dates, responsibilities, and outcomes.
- Update project status and add screenshots/demo links when available.

## Motion
GSAP is used only for a short hero entrance and one-time scroll reveals. No cursor-following effects, parallax, or looping animation. Reduced-motion preferences are respected.
